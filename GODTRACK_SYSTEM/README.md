# GODTRACK STRATEGY SYSTEM V8.0 | GOD MODE EDITION

## 🚀 MODO DE USO
**SOLO HAY UN PASO:**
1. Haz doble clic en **`INICIAR GODTRACK.EXE`**.

Esto hará todo por ti:
*   Arranca el Servidor Neural (Backend).
*   Abre tu navegador Chrome/Edge automáticamente en el panel de control.
*   Cuando termines, simplemente cierra la ventana de la consola.

---

## 📂 ESTRUCTURA DEL SISTEMA
*   **`INICIAR GODTRACK.EXE`**: El corazón del sistema. Tu único botón.
*   **`backend/`**: Código Python (Cerebro: Física, Cálculos, IA).
*   **`frontend/`**: Código Visual (Interfaz, Gráficos, Estilos).
*   **`data/`**: Archivos de datos (ej. lista de calles `carrerer.csv`).
*   **`tests/`**: Pruebas automáticas de integridad.

## ⚠️ NOTA
Si necesitas modificar el código, los cambios en `frontend` (HTML/JS/CSS) se aplican instantáneamente al recargar la página.
Los cambios en `backend` (Python) requieren reiniciar el `INICIAR GODTRACK.EXE`.
